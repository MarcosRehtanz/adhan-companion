# Adhan Companion v0.1.12

Actualización desde la app también en Windows y con el paquete .deb. Disponible para Linux x64 (.deb y AppImage), Windows x64 (instalador NSIS) y Android ARMv7/ARM64 (APK release firmados).

## Novedades

- **Actualizar ahora en Windows:** Configuración → Actualizaciones descarga el instalador, verifica su SHA-256 contra la release y lo instala encima, sin desinstalar la versión anterior ni preguntar. La app se cierra y vuelve a abrirse en la versión nueva. Se conservan los accesos directos, el inicio automático y todos los datos.
- **Actualizar ahora con el paquete .deb:** descarga el paquete, verifica su SHA-256 y lo instala con apt; Ubuntu pide tu contraseña. Después la app vuelve a abrirse.
- **AppImage y Android** siguen actualizándose como hasta ahora.

## Correcciones

- En Windows, buscar actualizaciones ya no abre una ventana de consola por un instante.

## Actualizar a esta versión

Esta es la última actualización manual en escritorio: desde v0.1.12, las siguientes se instalan con **Actualizar ahora**.

- **Windows:** ejecutar el instalador nuevo. Si muestra «Ya instalado», elegir **No desinstalar** y continuar. Otra opción es ejecutarlo desde PowerShell con `/P /UPDATE /R`, que instala encima sin páginas. Elegir «Desinstalar antes de instalar» no borra tus datos, que están en `%APPDATA%\Adhan Companion`, pero no hace falta.
- **Linux .deb:** instalar el .deb nuevo (por ejemplo, `sudo apt install ./Adhan.Companion_0.1.12_amd64.deb`).
- **Linux AppImage:** Configuración → Actualizaciones → Actualizar ahora.
- **Android:** Configuración → Actualizaciones. Compilación **1011200**, misma identidad y certificado que 1011100; esta versión no trae cambios para Android.

Windows no tiene firma de código: SmartScreen puede advertir al ejecutar un instalador descargado con el navegador («Más información» → «Ejecutar de todas formas»). Las actualizaciones hechas desde la app no pasan por el navegador.

El flujo de actualización se probó en un equipo con Linux (.deb) y en uno con Windows, actualizando una compilación de prueba a la v0.1.11.
