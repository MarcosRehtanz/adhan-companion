# Adhan Companion v0.1.21

Corrección y robustez del flujo de autorización OAuth de Google Drive en Android (resolución del desajuste de `state` y soporte para Android 14). Disponible para Linux x64 (.deb y AppImage), Windows x64 (instalador NSIS) y Android ARMv7/ARM64 (APK release firmados).

## Novedades

- **Resolución del error de `state` en Android:** Se solucionó el fallo que provocaba el mensaje *«la respuesta de Google no coincide con el pedido (state) y se descartó»*. El bucle de espera ahora descarta callbacks obsoletos de intentos previos sin abortar la sesión activa, esperando el callback correspondiente al intento actual.
- **Limpieza de callbacks residuales y datos de Intent:** Al iniciar la conexión y al procesar el callback en `MainActivity`, se limpia el URI residual para impedir que giros de pantalla, cambios de configuración o aperturas desde la lista de aplicaciones recientes reinyecten solicitudes viejas.
- **Tolerancia a fragmentos `#` en la redirección:** `parsear_callback` ahora limpia fragmentos como `#` o `#_=_` que Chrome y otros navegadores modernos agregan al final de la redirección, asegurando que `state` y `code` se lean con total exactitud.
- **Reporte directo de errores de Google:** Si la autorización es rechazada o cancelada en el navegador, se presenta el mensaje de error correspondiente en vez de un fallo confuso de estado.
